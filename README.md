# Pandas DataFrame Assignment

## Project Overview

This project demonstrates how to create, save, reload, and explore a student DataFrame using Python and Pandas.

## Tasks Performed

- Imported the Pandas library.
- Created a student DataFrame using a Python dictionary.
- Saved the DataFrame as `students.csv`.
- Reloaded the CSV file using Pandas.
- Displayed the first 3 rows using `df.head(3)`.
- Generated statistical information using `df.describe()`.
- Checked the DataFrame shape using `df.shape`.
- Checked column data types using `df.dtypes`.
- Displayed DataFrame information using `df.info()`.
